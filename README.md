# Patrimonio Estratégico Pro

Dashboard patrimonial personalizable para holding, inmuebles, negocios operativos, cartera y esfera personal: balance, flujos, escenarios, simulaciones y exportación a PDF.

- **Escritorio:** panel completo con supuestos a la izquierda.
- **Móvil:** versión estilo *liquid glass* con pestañas inferiores y panel de supuestos como hoja deslizable. Se puede añadir a la pantalla de inicio (Safari → Compartir → «Añadir a pantalla de inicio»).

## Uso

Abre `patrimonio.html` en el navegador (o la URL de GitHub Pages). No necesita instalación ni servidor.

## Privacidad

Los datos se guardan **solo en el navegador de cada dispositivo** (`localStorage`); este repositorio no contiene ningún dato personal. Para pasar los datos de un dispositivo a otro, usa **Exportar datos** e **Importar datos** (archivo JSON).

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `patrimonio.html` | La aplicación completa (un solo archivo). |
| `index.html` | Redirige a `patrimonio.html` (página de entrada en GitHub Pages). |
| `manifest.webmanifest`, `icons/` | Icono y modo app al añadirla a la pantalla de inicio. |

Las cifras son orientativas y no constituyen asesoramiento financiero ni fiscal.
